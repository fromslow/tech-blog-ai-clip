# 테크 블로그 AI 클리핑

국내 주요 테크 기업 기술 블로그에서 **AI·머신러닝 관련 글만 자동으로 모아** 보여주는 웹사이트입니다.
디자인은 원티드 **Montage** 디자인 시스템(다크 우선 · Wanted Sans · 그라디언트)에서 영감을 받았습니다.

**수집 대상 (9개사):** 토스 · 쏘카 · 배달의민족 · 당근 · 카카오 · 네이버 · 라인 · 뱅크샐러드 · 컬리

## 핵심 개념 — 최근 1년 롤링 누적
- 실행할 때마다 새 글을 가져와 **기존 데이터에 누적**하고 URL로 중복을 제거합니다.
- 발행일이 **1년(365일) 지난 글은 자동으로 제거**해 "최근 1년 AI 아카이브"를 유지합니다.
- 매일/매주 실행하면 데이터가 계속 쌓입니다. 처음 3일 이내에 새로 추가된 글에는 카드에 **NEW** 배지가 붙습니다.

## 화면 기능
- 기업별 필터(브랜드 컬러) · AI 주제 태그 필터(#AI, #LLM, #RAG, #추천, #MLOps …)
- 제목·내용·키워드 검색, 최신순/기업순 정렬
- 카드 썸네일(없으면 브랜드 그라디언트 플레이스홀더), 클릭 시 원문 열기
- 다크/라이트 테마 토글(브라우저에 기억됨), 모바일 반응형

## 보는 방법
로컬 서버로 실행 (Wanted Sans 웹폰트 로드를 위해 인터넷 필요):
```bash
cd "/Users/suyeon/AI Clipping"
.venv/bin/python serve.py          # http://localhost:4599
```
> `index.html` 더블클릭으로도 열리지만, 일부 브라우저는 로컬 폰트/스크립트 보안정책 때문에 서버 실행을 권장합니다.

## 데이터 누적(새로고침)
```bash
cd "/Users/suyeon/AI Clipping"
.venv/bin/pip install -r requirements.txt   # 최초 1회
.venv/bin/python fetch_feeds.py             # 새 글 수집 → 누적 → data.js / data.json 갱신
```
> 자동 수집(launchd)이 매일 오전 8:30에 이 과정을 대신 실행합니다.
실행 결과 예시: `이전 누적 83건 | 신규 추가 33건 | 1년 경과 제거 10건 | 현재 누적 106건`

## 과거 글 백필(backfill)
| 소스 | 방식 | 과거 1년 확보 |
|------|------|:---:|
| 배달의민족 | WordPress REST API | ✅ 즉시 전량 |
| 네이버(D2) | D2 목록 API 페이지네이션 | ✅ 즉시 전량 |
| 토스·쏘카·당근·카카오·라인·뱅크샐러드·컬리 | RSS | 🔸 피드 제공 범위 |

RSS 소스는 각 블로그가 피드에 노출하는 최근 글까지만 즉시 확보되고(당근/카카오 ~10건, 컬리 ~120건 등),
**이후 스크립트를 주기적으로 돌리면 새 글이 계속 누적**되어 1년 아카이브가 완성됩니다.

## 파일
| 파일 | 설명 |
|------|------|
| `index.html` | 웹사이트 (Montage 스타일 뷰어) |
| `fetch_feeds.py` | 수집 + AI 필터 + 1년 누적 로직 |
| `data.js` / `data.json` | 누적된 AI 글 데이터 (자동 생성) |
| `serve.py` | 로컬 미리보기 서버 |
| `requirements.txt` | 의존성 (feedparser, curl_cffi) |

## 커스터마이징
- **소스 추가/변경:** `fetch_feeds.py` 의 `SOURCES` 리스트 (`type`: rss / wordpress / d2)
- **AI 판별 키워드:** 같은 파일의 `ACRONYMS` / `PHRASES`
- **누적 기간:** `WINDOW_DAYS` (기본 365)

## 기술 메모
- 배민 등 일부 블로그는 TLS 지문 기반 WAF로 일반 요청을 차단합니다. `curl_cffi` 로 크롬을 위장해 통과합니다.
- 요청 사이에 지연을 두어 서버 부하를 피합니다.
